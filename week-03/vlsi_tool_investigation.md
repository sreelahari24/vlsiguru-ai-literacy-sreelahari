# VLSI Physical Design Tool Investigation: Cadence Innovus

## 1. Tool Name

Cadence Innovus Implementation System

## 2. Introduction

Cadence Innovus is a commercial Electronic Design Automation (EDA) tool used for digital VLSI Physical Design. It helps transform a synthesised digital design into a physical implementation suitable for further verification and manufacturing.

Official Website: https://www.cadence.com/

Product Information: https://www.cadence.com/en_US/home/tools/digital-design-and-signoff/soc-implementation-and-floorplanning/innovus-plus-synthesis-implementation-system.html

## 3. Relevance to My Track

My VLSI track is Physical Design (PD). Cadence Innovus is relevant to this track because it supports important stages of the digital Physical Design flow, including floorplanning, placement, clock tree synthesis, routing, and design optimisation.

## 4. Important Features

- Floorplanning and physical design setup.
- Standard cell placement.
- Clock tree synthesis (CTS).
- Signal routing.
- Timing optimisation.
- Power, performance, and area (PPA) optimisation.
- Design implementation reports.

## 5. Basic Physical Design Flow

1. Import the synthesised netlist and technology libraries.
2. Define the floorplan and design constraints.
3. Plan the power distribution network.
4. Perform standard cell placement.
5. Perform clock tree synthesis.
6. Route signal connections.
7. Optimise timing and physical design quality.
8. Review implementation reports and perform required design checks.

The exact flow depends on the project requirements and tool configuration.

## 6. Advantages

- Supports major digital Physical Design activities.
- Provides placement, routing, and optimisation capabilities.
- Helps engineers analyse timing and physical design quality.
- Is used in professional digital IC implementation workflows.

## 7. Limitations

- Cadence Innovus is commercial and is not open-source software.
- Access generally requires an appropriate licence.
- Users need suitable technology libraries, design files, and constraints.
- Results depend on the design, configuration, and implementation requirements.

## 8. Learning Outcome

This investigation helped me understand how Cadence Innovus supports the digital Physical Design flow. The tool connects theoretical concepts such as placement, clock tree synthesis, routing, and timing optimisation with practical chip implementation.

It also helped me recognise the difference between commercial EDA tools and open-source alternatives.
