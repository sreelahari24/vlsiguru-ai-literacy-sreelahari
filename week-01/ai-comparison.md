# Week 01 - AI Comparison Exercise

## Question Asked

I tested the same factual question with two different AI assistants.

**Question:** What is the difference between RAM and ROM?

## 1. ChatGPT Response

| RAM | ROM |
|---|---|
| Random Access Memory | Read-Only Memory |
| Temporary memory | Non-volatile memory |
| Data is lost when power is turned off | Data is retained when power is turned off |
| Used while the computer is running | Used to store firmware and startup instructions |
| Can be read from and written to frequently | Traditionally read-only, although some modern ROM types can be rewritten |
| Example: Programs currently running | Example: Firmware used during device startup |

**Summary:**

- RAM = Working memory that stores data temporarily.
- ROM = Stored instructions that remain available after the power is turned off.

## 2. Gemini Response

Gemini explained that RAM and ROM serve different roles in a computer or microcontroller system.

**RAM (Random Access Memory)**

RAM acts as the system's temporary workspace. It is volatile memory, meaning that its stored data is lost when power is disconnected. Applications, running software, and live sensor data can be stored in RAM because the processor frequently reads from and writes to it.

**ROM (Read-Only Memory)**

ROM is non-volatile memory designed to retain its contents even when the device is powered off. It stores important system instructions, such as firmware or bootloader code, that help initialise the hardware and start the system.

## 3. Comparison of the AI Responses

| Comparison Point | ChatGPT | Gemini |
|---|---|---|
| Explanation style | Presented the differences in a table | Explained the concepts in paragraphs |
| RAM | Described it as temporary, volatile working memory | Explained its role as temporary workspace for running applications and processing data |
| ROM | Described it as non-volatile memory used for firmware and startup instructions | Explained its role in storing firmware and bootloader instructions |
| Examples | Programs currently running and startup firmware | Applications, sensor data, firmware, and bootloader code |
| Main takeaway | RAM is temporary working memory, while ROM retains stored instructions | RAM supports active processing, while ROM retains important startup instructions |

Both assistants provided similar explanations of the main differences between RAM and ROM, but they presented the information in different formats and levels of detail.
